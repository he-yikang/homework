## 作品二：1000 以内质数生成器

**工具：** DeepSeek Codex · V4-Pro

使用试除法生成 1000 以内的所有质数，共 168 个。核心思路：对每个数 p，只需检查 2 到 √p 之间的整数能否整除，若都不能整除就是质数。
